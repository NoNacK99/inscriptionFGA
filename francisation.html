Comment envoyer votre formulaire

  2. Choisissez votre application de courriel dans le menu qui s'ouvre.
  3. Dans la case « À », appuyez longuement avec le doigt, puis choisissez « Coller ».
  4. Vérifiez que le PDF est joint, puis appuyez sur « Envoyer ».
